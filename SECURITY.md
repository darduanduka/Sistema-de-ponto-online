# Segurança

Este repositório contém apenas uma versão sanitizada para estudo e portfólio.

Não publique neste projeto:

- `.env` ou arquivos equivalentes;
- `APPS_SCRIPT_URL` real;
- tokens e credenciais;
- nomes/IDs de funcionários reais;
- fotos, endereços ou dados de ponto reais;
- e-mails internos da empresa.

A versão de exemplo não implementa autenticação. Para produção, trate os endpoints de funcionários, histórico e registro como superfícies que exigem uma política de acesso adequada ao contexto de uso.
